# מסמך עיצוב: אפליקציית תזונה ומשקל (PWA)

תאריך: 24.10.2026
מצב: ממתין לאישור

## 1. מטרה
אפליקציה בעברית (RTL) לטלפון אנדרואיד, שעוזרת לכל מי שמתקין אותה לרדת במשקל בצורה בריאה.
הצלחה: פותחים את האפליקציה ותוך שנייה רואים כמה נשאר לאכול היום, איך המשקל מתקדם, ומתי מגיעים ליעד.

## 2. משתמשים
- כל מי שמתקין. אין נתונים אישיים קבועים בקוד.
- כל משתמש עובד על מכשיר אחד.
- כל משתמש מתחבר לגוגל דרייב שלו, ומזין מפתח Claude API משלו.
- פנייה לפי המין שבהגדרות (זכר / נקבה). בלי מין: ניסוח ניטרלי. הפונקציה `g(זכר, נקבה, ניטרלי)`.

## 3. פלטפורמה
- PWA שמותקן מ-Chrome באנדרואיד ("התקן אפליקציה").
- HTML, CSS ו-JS רגילים, בלי שלב בנייה. Node משמש רק לבדיקות.
- אירוח ב-GitHub Pages (https).

## 4. אחסון וסנכרון
- **עותק עבודה בטלפון**: IndexedDB. האפליקציה תמיד עובדת מולו, גם בלי אינטרנט.
  - מעבר מ-localStorage (שלבים 1-3) ל-IndexedDB, עם העברה אוטומטית של נתונים קיימים.
- **גוגל דרייב**: התחברות עם Google Identity Services, הרשאת `drive.file` בלבד.
  - תיקייה גלויה "תזונה ומשקל":
    - `data.json`: כל הנתונים העדכניים.
    - `backups/YYYY-MM-DD.json`: גיבוי יומי. נשמרים 30 האחרונים.
- **סנכרון אוטומטי**: כמה שניות אחרי שינוי, `data.json` מתעדכן. בלי אינטרנט, ממתין ומסנכרן כשחוזר.
- **אין מיזוג**: מכשיר אחד למשתמש, ולכן הטלפון הוא המקור.
- **רענון**: מושך את `data.json` מהדרייב ומחליף את העותק בטלפון.
- **שחזור**: רשימת גיבויים לפי תאריך. לפני שחזור נשמר גיבוי נוסף של המצב הנוכחי.
- **מטמון של האפליקציה**: Service worker שומר את קבצי האפליקציה. גרסה חדשה יורדת ברקע ומוצגת הודעה "יש עדכון".
- **סמן סנכרון**: "מסונכרן" / "ממתין לאינטרנט" / "צריך להתחבר מחדש".
- **הגבלה ידועה**: בלי שרת, החיבור לגוגל פג אחרי כשעה ומתחדש, לפעמים בלחיצה. עד אישור Google, עד 100 משתמשים שמוגדרים ידנית.

## 5. מבנה הנתונים
```
{
  version, updatedAt,
  profile: { name, birthYear, sex, height, activity, goalWeight, goalFat, waterGoal, overrides },
  measurements: [ { date, weight, fat, waist, height, cycle } ],
  days: { "YYYY-MM-DD": { meals: { breakfast, lunch, dinner, snacks: [item] }, water, coffee: [typeId], steps } },
  savedMeals: [ { id, name, items } ],
  recentItems: [item],
  coffeeTypes: [ { id, name, kcal, protein, fat, carbs, fiber, sugar, sodium } ],
  settings: { reminders, apiKeySet }
}
item = { name, grams, kcal, protein, fat, carbs, fiber, sugar, sodium, source: list|ai|manual }
```
מפתח ה-API נשמר רק בטלפון, לא בדרייב.

## 6. חישובים
- **BMR**: Mifflin-St Jeor. כשיש אחוז שומן: Katch-McArdle.
- **TDEE** = BMR × רמת פעילות. התקציב קבוע ופעילות לא מוסיפה לו.
- **יעד יומי**: TDEE פחות כ-500 קלוריות, עם רצפה בטוחה (1,200 לנקבה, 1,500 לזכר).
- **מאקרוס**: חלבון לפי משקל גוף, שומן 25-30%, השאר פחמימות. סיבים כ-25 גרם.
- כל מדידה חדשה מעדכנת את היעדים. אפשר לדרוס ידנית.
- **חריגה מהתקציב**: מוצגת באדום, בלי קיזוז.
- **מגמה**: רגרסיה על 28 הימים האחרונים, הערכת תאריך ליעד, ואזהרה כשהירידה מעל 1% ממשקל הגוף בשבוע.

## 7. מסכים (סגנון "צלחת")
- **שפה חזותית**: רך ועגול, ירוק עמוק (#1F3B33) על רקע בהיר (#F5F7F4), צבעי מזון למאקרוס (זית #7A8B3A, חומוס #D9B46A, רימון #B8324A). גופן Rubik. מצב כהה לפי הטלפון.
- **ראשי**: צלחת במרכז עם הקלוריות שנותרו ופרוסות מאקרוס. אריחים למים, קפה וצעדים. משקל, שינוי שבועי ותאריך יעד. סמן סנכרון. כניסה לסיכום השבועי.
- **ארוחות**: בוקר, צהריים, ערב ונשנושים. כפתור + פותח חלונית: צילום / חיפוש ברשימה / תיאור חופשי, ובחירת ארוחה. עריכה ומחיקה של כל פריט. ארוחות שמורות ורשימת "אחרונים". סיכום של מה נאכל ומה נותר, כולל גרעון.
- **מדדים**: גרף לכל מדד (משקל, אחוז שומן, מותניים) עם קו יעד, ממוצע 7 ימים למשקל וימי מחזור. טופס מדידה והיסטוריה. מבוסס על שלב 3 הקיים, בעיצוב החדש.
- **פעילות**: צעדים ידנית (אין גישה לחיישן מהדפדפן) וגרף שבועי.
- **סיכום שבועי**: ממוצעים, שינוי משקל, ימים בתקציב, וטיפ קצר מ-AI.
- **הגדרות**: פרטים אישיים, דריסת יעדים, מפתח API, חיבור לדרייב, רענון ושחזור, תזכורות עם מתג, סוגי קפה, יעד מים.

## 8. AI (Claude API)
- קריאה ישירה מהדפדפן ל-`api.anthropic.com` עם הכותרת `anthropic-dangerous-direct-browser-access`.
- צילום או טקסט חופשי: התשובה היא JSON של פריטים (כמות, קלוריות, מאקרוס, סיבים, סוכר, נתרן). אפשר לתקן לפני השמירה.
- טיפ שבועי: סיכום מספרי נשלח, ומתקבל טיפ קצר.

## 9. תזכורות
- התראות דפדפן עם מתג לכל סוג (שקילה, מים, ארוחות).
- מגבלה: בלי שרת, אין הבטחה להתראה בשעה מדויקת כשהאפליקציה סגורה. כשהאפליקציה נפתחת מוצגת תזכורת על מה שהוחמץ.

## 10. שגיאות
- **אין אינטרנט**: עובד כרגיל, הסמן "ממתין לאינטרנט".
- **פג החיבור לגוגל**: כפתור "התחבר מחדש". הנתונים בטלפון לא נפגעים.
- **AI לא זיהה**: הטקסט נשאר, ואפשר לחפש ברשימה או להזין ידנית.
- **מפתח API חסר או שגוי**: הודעה עם קישור להגדרות.
- **קובץ גיבוי פגום**: השחזור מתבטל והנתונים לא משתנים.

## 11. בדיקות
- בדיקות יחידה עם Node לחישובים, מגמה, העברת נתונים ובניית קובץ הסנכרון.
- בדיקת מסכים בדפדפן בגודל טלפון, עם צילום מסך.
- בטלפון: התקנה, עבודה בלי אינטרנט, סנכרון לדרייב, רענון ושחזור.

## 12. מחוץ לתחום
- שינה, רעב ומצב רוח.
- כמה מכשירים לאותו משתמש.
- קריאת צעדים אוטומטית.
- תקציב שבועי או קיזוז חריגות.
