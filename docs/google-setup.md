# הגדרת חיבור לגוגל דרייב

עושים את זה פעם אחת, לפני ההעלאה לאינטרנט. זה חינמי.
בסוף מקבלים "מזהה לקוח" (Client ID) ומדביקים אותו בקובץ `js/config.js`.

שמות הכפתורים במסוף של Google משתנים מדי פעם. אם משהו לא נראה בדיוק כך, מחפשים את השם הקרוב.

## 1. פרויקט חדש
1. נכנסים ל-https://console.cloud.google.com עם חשבון הגוגל שלך.
2. למעלה, ליד הלוגו, בוחרים פרויקט ← "New project".
3. שם: `תזונה ומשקל` (או כל שם). לוחצים "Create" ובוחרים בפרויקט החדש.

## 2. הפעלת Drive API
1. בתפריט: "APIs & Services" ← "Library".
2. מחפשים `Google Drive API`, נכנסים ולוחצים "Enable".

## 3. מסך ההסכמה (מה שהמשתמשים רואים בהתחברות)
1. בתפריט: "Google Auth Platform" (או "OAuth consent screen").
2. "Get started": שם האפליקציה `תזונה ומשקל`, מייל תמיכה, וסוג קהל **External**.
3. ב-"Audience" מוסיפים ב-"Test users" את כתובות הג'ימייל של כל מי שישתמש באפליקציה.
   - כל עוד האפליקציה במצב בדיקה (Testing), רק המשתמשים ברשימה יכולים להתחבר. עד 100 משתמשים.
4. ב-"Data access" לוחצים "Add or remove scopes" ומוסיפים רק את:
   `https://www.googleapis.com/auth/drive.file`
   ההרשאה הזו נותנת לאפליקציה גישה רק לקבצים שהיא יצרה, לא לשאר הדרייב.

## 4. מזהה לקוח
1. ב-"Clients" ← "Create client".
2. סוג: **Web application**.
3. ב-"Authorized JavaScript origins" מוסיפים:
   - `https://<שם-המשתמש-שלך>.github.io` (הכתובת של GitHub Pages, בלי נתיב ובלי / בסוף)
   - לבדיקות במחשב אפשר להוסיף גם `http://localhost:8080`
4. לא צריך "Redirect URIs".
5. "Create" ← מעתיקים את ה-Client ID (נגמר ב-`.apps.googleusercontent.com`).

## 5. הדבקה באפליקציה
בקובץ `js/config.js`:
```js
GOOGLE_CLIENT_ID: '1234567890-abc.apps.googleusercontent.com',
```
מזהה הלקוח אינו סוד, ומותר שיופיע בקוד.

## כשרוצים לפתוח לכולם
- כדי שמשתמשים שלא ברשימה יוכלו להתחבר, לוחצים "Publish app" ב-"Audience".
- Google עשויה לבקש אימות של האפליקציה. ההרשאה `drive.file` נחשבת אצל Google פחות רגישה, ולכן התהליך אמור להיות פשוט יחסית, אבל ההחלטה אצלם.

## מגבלות שכדאי לדעת
- בלי שרת, ההתחברות לגוגל פגה אחרי כשעה. האפליקציה מציגה "צריך להתחבר מחדש", ולחיצה אחת מחברת שוב. הנתונים בטלפון לא נפגעים בינתיים.
